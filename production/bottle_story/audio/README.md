# English neural narration

This is synthetic narration, not a recording of a project author. Voice: `en-US-AriaNeural` via the `edge-tts` package. No reference-film audio, cloned voice, music, or ambient robot sound is used.

- **Film length:** 174.000 seconds; 11 scenes; 343 spoken words.
- **Master:** `narration.wav` (48 kHz mono PCM) or `narration.m4a` (AAC 160 kbit/s); loudness normalized toward -16 LUFS, peak limited to -1.5 dBTP.
- **Renderer contract:** `narration.json`; scene start/end and subtitle times are absolute film seconds. Per-scene audio filenames are relative to this directory. These unnormalized scene WAV files are padded to their exact scene lengths; use the combined master for the final film.
- **Captions:** `narration.srt` and `narration.vtt`; 50 cues, maximum 77 characters. Timings use actual neural speech word boundaries, with original punctuation restored. They are not estimated from reading speed.
- **Source:** `narration-source.json`; `synthesize.py` regenerates the mix and captions. Install `edge-tts` in an isolated Python environment. FFmpeg and FFprobe must be available. Online synthesis is required for changed sentences; unchanged segments are reused from existing metadata and MP3 files.
- **Delivery:** calm English narration, with brief pauses for diagram reading. Scene-level speech rates are recorded in `narration.json` (3–12% relative to the neural voice default).

The graph, policy, and frame-transfer wording explains the architecture. It does not assert that the recorded task-specific robot run was generated by the illustrative pseudocode. The final place-aside node belongs to the human demonstration; the documented robot run ends at cap lift. The bottle run uses relative raw force-channel proxies, not calibrated torque. Torque is shown as an available library branch, unselected for this run.
